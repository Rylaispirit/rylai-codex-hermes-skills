# Precise Academic Vocabulary

> Portable Codex-Hermes replacement authored by Rylai.

Prefer accurate common words over ornate synonyms.

| Weak or vague | Prefer when accurate |
|---|---|
| shows | demonstrates, indicates, reports |
| looks at | examines, evaluates, analyzes |
| gets better | improves, increases, reduces error |
| a lot of | many, substantial, or an exact value |
| very important | central, necessary, or state the consequence |
| new | proposed, previously untested, or describe the novelty |
| bad performance | lower accuracy, higher error, slower runtime |
| deals with | addresses, models, estimates, controls |
| uses | applies, incorporates, conditions on |
| proves | supports, demonstrates under the tested conditions |

## Calibrating Claims

- Strong evidence: demonstrates, consistently outperforms, establishes under.
- Moderate evidence: supports, suggests, is associated with.
- Exploratory evidence: indicates, may reflect, motivates further study.
- Negative result: does not improve, remains within uncertainty, is inconclusive.

## Transitions By Function

- Add evidence: furthermore, in addition, consistently.
- Contrast: however, in contrast, whereas.
- Narrow a claim: specifically, under this setting, for this dataset.
- Explain cause carefully: because, due to, consistent with.
- Sequence: first, subsequently, finally.

## Common Repairs

- "In order to" -> "To"
- "Due to the fact that" -> "Because"
- "It can be seen that" -> state the observation directly
- "A large number of" -> "Many" or the exact coun
- "Has the ability to" -> "Can"
- "In terms of" -> name the dimension directly

Do not replace technical terms merely to create variety. Terminology consistency
is more important than synonym diversity.
