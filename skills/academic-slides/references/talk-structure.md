# Academic Talk Structures

> Portable Codex-Hermes-Claude replacement authored by Rylai.

## Conference Talk

Problem -> gap -> key idea -> method overview -> strongest results -> limits ->
conclusion. Cut implementation detail before cutting motivation or interpretation.

## Thesis Defense

Research program -> questions -> contributions -> chapter or study sequence ->
cross-study synthesis -> limitations -> future agenda. Keep a visible map so the
committee knows where each chapter fits.

## Lab Meeting

Decision or question -> current evidence -> unresolved issue -> proposed next
experiment -> risks -> requested feedback. Show enough implementation detail for
peers to challenge the plan.

## Grant Briefing

Need -> opportunity -> proposed work -> feasibility evidence -> milestones ->
risk controls -> expected impact -> requested support.

## Public Research Talk

Concrete story -> surprising question -> intuitive mechanism -> selected
evidence -> real-world meaning -> honest limits -> memorable close.

For every structure, read action titles in order and remove slides that do no
advance the argument.
